# Projects

The chapter tour taught one device at a time. Real builds mix them — and mixing
is where the design questions live: who shares which connector, what happens
when one device fails to start, how fast can each loop run.

| Project | Devices | What it teaches |
|---------|---------|-----------------|
| [Clown house](clown-house.md) | All eight connectors at once | Wiring and initializing a full system |
| [Sound recorder](sound-recorder.md) | Sound sensor + your computer | Streaming real data to a host program |
